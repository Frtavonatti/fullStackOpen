      <div class="home"><h1 class="page-heading">In English</h1><h1 id="main-title">Welcome to the course page of the course Computing tools for CS studies, or Lapio </h1>
<p>This course is primarily designed for CS freshmen, and its purpose is to go through the basics of the command line in a Unix-like system, using Git for version control, and building a static website using HTML and CSS. The course’s nickname “lapio” is Finnish, and it simply means “shovel”, as the course teaches the basic use of the essential tools in Computer Science.
The course is passed with an online exam, which is held in <a href="https://moodle.helsinki.fi/course/view.php?id=62556">Moodle</a>, an e-learning environment widely used in the University. In order to enter the course  in Moodle, you will need to enter a key, which is is <strong>lapio-on-tyovaline</strong>. The exam questions are primarly based on the material provided on this Website, which is divided into three sections, each covering a different subject: the command line, Git and Github, and static websites.</p>

<p>If you have experience of using the command line, Git and HTML/CSS, you are free to take the exam right away, without reading the material or doing the exercises. At the start of each section there is a list of learning goals, which will help you determine whether you should read the material or not. Even if you don’t read the material, make sure to go through <a href="/departments-systems">this page</a> as it provides important information about the department’s IT systems.</p>

<p>However, if you are not familiar with the tools discussed on this course, go through the material carefully. The course will cover skills you will definitely need in your CS studies and in the working life. There are exercises embedded in the material, and doing them will earn you course points. Read the <a href="/exam">grading</a> page for more information.</p>

<h2 id="assistance">Assistance</h2>

<p>Course uses Discord server for remote assistance.
<a href="https://study.cs.helsinki.fi/discord/join/lapio">Link to Discord servre</a></p>

<p>You are free to ask any questions you have with regards to the exercises, the course, or the exam.</p>

<p>Degrading, discriminatory or offensive language is not allowed, and will result in actions against the commenter.</p>

<p>In addition to Discord server, there will be face-to-face assistance available at some point later. <!--You can find timetable [here](/paja) ---></p>

<h2 id="tools">Tools</h2>

<p>The exercises can be done using any Unix-type operating system. In practice, this often refers to a Linux or a MacOS computer. If possible, we recommend doing all exercises, excluding the SSH exercise in part one, to be done using the department’s lab computers, which have the University’s own Linux distribution, <a href="https://wiki.helsinki.fi/display/it4sci/Cubbli+Linux">Cubbli</a>, installed on them.</p>

<p>If you only have access to a Windows computer, there are several things you can do. Otherwise passing the course doesn’t make much sense, as the point is to get to know using Unix-like systems.</p>

<h3 id="windows-subsystem-for-linux"><strong>Windows Subsystem for Linux</strong></h3>

<p>Windows 10 allows for installation of Ubuntu as an application. This way you can get Linux-environment good for this course without trouble.</p>

<p>Installing Windows Subsystem for Linux:</p>

<ol>
  <li>Launch <a href="https://www.thewindowsclub.com/how-to-open-an-elevated-powershell-prompt-in-windows-10">Elevated Powershell</a> and copy to window 
<br /><em>Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Windows-Subsystem-Linux</em>
<br />(Code installs the feature if it’s not yet installed. <strong>NEVER run any code you get online unless you know what it does</strong>)</li>
  <li>Install ‘Ubuntu’ application <a href="https://www.microsoft.com/fi-fi/p/ubuntu/9nblggh4msv6?activetab=pivot%3Aoverviewtab">From Microsoft Store</a>.</li>
  <li>Launch Ubuntu application and create user to use in it.</li>
</ol>

<p>More exact installation guide available <a href="https://docs.microsoft.com/en-us/windows/wsl/install-win10">here</a>.</p>

<p>If using only textbased environment feels too scary or for some other reason you can’t or don’t want to use Subsystem you can install Ubuntu in VirtualBox instance.</p>

<h3 id="virtualbox"><strong>VirtualBox</strong></h3>

<p>Before installing VirtualBox, make sure you have at least 512M, preferably 1G of <a href="https://www.computerhope.com/issues/ch000149.htm">free RAM</a> left free on your machine.</p>

<p>Installing VirtualBox</p>

<ol>
  <li>Download and install VirtualBox from <a href="https://www.virtualbox.org/wiki/Downloads">here</a></li>
  <li>Download the desktop image (.iso) of Ubuntu 22.04 <a href="http://releases.ubuntu.com/22.04/">here</a>. The contents of the file .iso are similar to a CD which you would use to install an operating system.</li>
  <li>Follow <a href="http://www.psychocats.net/ubuntu/virtualbox">these</a> instructions in order to create the virtual machine.</li>
  <li>Launch the virtual machine from VirtualBox.</li>
</ol>

<p>Don’t be afraid to ask for help, and please give us feedback, if the material can be improved with regards to instructions for Windows users!</p>

<h2 id="before-you-start-reading-the-material">Before you start reading the material</h2>

<p>Passing the course on your personal computer might require installing some software. If you don’t plan on passing the course on the department’s computer labs’ computers, make sure you are able to install software on the computer you will be using.</p>

<p>If you are working on a personal computer, you should install <a href="https://www.eduroam.org/what-is-eduroam/">Eduroam</a>, which will grant you a secure access to the Internet while on campus. <a href="https://helpdesk.it.helsinki.fi/en/instructions/logging-and-connections/networks/setting-eduroam-installer-package">Here</a> are the instructions. Note that you can also use it overseas and on mobile devices.</p>

<h2 id="material-reading-guides">Material reading guides</h2>

<p>The percentage after an exercise states what is its relative weight of that weeks exercises.</p>

<p>The material is built in a way which allows following along the examples. We recommend doing that.</p>

<p>If you find any errors or typos, you can fork <a href="https://github.com/tkt-lapio/tkt-lapio.github.io">this</a> project, and create a pull request. If you don’t know what either of those mean, they are discussed at the end of the second part.</p>
